# About — portrait

Drop la tua foto qui come **`portrait.jpg`** (o `portrait.webp`). Il sito la
prende automaticamente. Specifiche:

- Dimensioni: 600 × 750 px (ratio 4:5) — verticale, formato editoriale
- Peso: < 200 kB
- Spazio colore: sRGB
- Crop: testa + spalle, sguardo verso obiettivo o leggermente di tre quarti

Se manca il jpg, il sito mostra `portrait.svg` come placeholder elegante.

## Convenzione di nomi

Solo due file vivono qui:
- `portrait.jpg` — la foto reale (da inserire)
- `portrait.svg` — placeholder grafico (già presente)
